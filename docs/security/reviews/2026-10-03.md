## Findings

### F1 A trial install's cookies reach every server on localhost

On a trial URL, `http://localhost` with or without a port, the setup session's cookie and the web session's cookies carry no `Secure` flag and no `__Host-` prefix, since the install is served over plain HTTP. A browser keeps cookies by host, not by port, so it sends them to every server on `localhost`, whatever its port: a dev server or any other local service the person visits in the same browser receives the setup session, or the web session of a signed-in member, and can act with it. Nothing in the code can keep them to the install's port; the install docs, which offer the trial URL, do not say so.

- Item: SR-1
- Requirement: self-host-install: `TIEHALL_URL` and TLS
- Fix: the install docs say that on a trial URL the browser sends the install's cookies to every server on localhost, so a trial runs in a browser profile that visits no other local server, and a real install uses HTTPS; a docs test checks the sentence.

## Decisions for the maintainers

What this review found that needs a new or changed spec rule, so no task builds it until an OpenSpec change does.

- D-1, SR-4 and SR-5: `/mcp` does not check a request's Origin header. The MCP transport asks servers to refuse a request whose Origin is present and not their own, against DNS rebinding. Tiehall's tokens are bearer tokens a browser never sends by itself, and `/mcp` sends no CORS headers, so no attack was found; refusing such a request with 403 would be new behavior of `/mcp`.
- D-2, SR-7: a request's body is read before anyone is authenticated, up to its limit (25 MiB for a GitHub delivery, 16 MiB for a contract report and 2 MiB elsewhere), and nothing caps how many bodies are read at once, so many large requests at once can exhaust the web role's memory. A cap needs a refusal the error model does not have, such as 503 with `Retry-After`.
- D-3, SR-11: the Compose file sets no memory or process limit on the app and the migrate step. `self-host-install: Tiehall's containers are confined` names none; a runaway process can take the host's memory.
