# Tasks

Nothing is built by this change: every rule it states is already in the code. The one group below verifies each item of D45 and D46 against the tests that cover it, and, where no test covers an item yet, writes that test first, as a plain test, because the behavior exists. A task is checked off when the named tests pass. Each task names the requirement it documents in brackets, as `capability: Requirement name`.
