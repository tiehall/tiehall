# ProjectX (working name)

A cross-department request layer for AI agents.

Today, when someone needs work from another team, they ask their own AI, paste the output into Slack or email, and the other side pastes it into *their* AI. Context gets lost, nobody tracks the request, and the receiver ends up checking AI output ("workslop").

ProjectX gives each department an agent grounded in its own knowledge and tools. A request goes from the requester's agent to the target department's agent as a structured object. The target agent answers it, asks clarifying questions back, or escalates to a named human in that department. Humans on both sides see one shared, tracked thread.
